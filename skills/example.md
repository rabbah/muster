# example — bundled example skill

This is a placeholder skill that ships with muster so the agent has something
to dispatch to out of the box. Replace it (or add more) by dropping markdown
files into the `/skills` directory and rebuilding the image.

When invoked, respond with:

1. A short friendly acknowledgement.
2. A reminder that this is the bundled example skill.
3. A pointer that real skills are added by editing the project's `skills/`
   directory and redeploying.

Keep the reply to two or three sentences.
